Undo (toast)CHRO-08
button

After a Tracking bulk delete or a catalog row, customer, shop drawing or sample archive is confirmed, a toast says what was done with an Undo button for 10 seconds. Nothing has been sent yet: Undo cancels the action; when the time ends (or the tab is closed or the app is left) the request is sent. Deleted Tracking rows disappear at once and come back on Undo.

API
none until the 10 seconds end; then the action’s own request
Who
any signed-in user (the action’s own permission still applies)
Roles
every role
